# 애매한 얼룩은 GPT로 확인 (2026-11-09)

정지원 결정(11-09): 애매한 얼룩은 지인에게 묻지 않고 GPT에게 묻는다. 얼룩 사진만 저장한다. GPT 확인은 앱을 처음 쓸 때 한 번 동의한 사용자에게만 쓴다.

## 흐름

| 우리 모델(v6) 확신도 | 하는 일 | 응답 |
| --- | --- | --- |
| 0.5 이상 | 바로 알림 | `defects[]`, `checkedBy: "model"` |
| 0.2 ~ 0.5 | 결함 둘레 조각만 GPT(gpt-4.1-mini)에게 물음 | 얼룩·찢어짐이면 `defects[]`, `checkedBy: "gpt"`. 아니면 버림 |
| 0.3 ~ 0.5인데 GPT를 못 씀 | 확인하지 못함 | 예전처럼 `pendingHelper`("확실하지 않은 부분이 있어요") |
| 0.2 ~ 0.3인데 GPT를 못 씀 | 버림(예전 기준 0.3과 같게, "확실하지 않아요"가 너무 잦지 않게) | |
| 0.2 미만 | 버림 | |

GPT를 못 쓰는 경우는 네 가지예요.
- 동의하지 않음: agent가 `allowGpt=true`를 넣지 않음.
- 키 없음: `OPENAI_API_KEY`가 비어 있음.
- GPT가 답하지 않음: 3초 안에 답이 없거나 오류가 남. 다시 보내지 않아요.
- 입은 사진에서 사진 위쪽 25%에 걸친 후보: 얼굴이 들어갈 수 있어서 보내지 않음.

## 보내는 것

- 결함 박스를 사방으로 박스 크기의 30%만큼 넓혀 자른 조각만 보냅니다.
  - 넓혀도 64px보다 작으면 64px까지 늘립니다.
  - 긴 변은 512px 이하로 줄이고, JPEG 품질 90으로 보냅니다.
- 옷 전체 사진은 보내지 않습니다.
- 요청 형식: Chat Completions, `response_format: json_object`, 그림 `detail: high`. 동시에 최대 4개를 보내요. 한 번에 3초까지만 기다리고, 넘기면 확인하지 못한 것으로 봐요. 사진 한 장 전체도 약 3.5초 안에 끝나요. agent는 MCP를 20초까지 기다려요.
- 프롬프트는 `OpenAiCropVerifier.PROMPT`에 있습니다. 시험(아래)과 같은 문장이라, 바꾸면 다시 재야 합니다.

## 저장하는 것

- GPT가 얼룩·찢어짐이라고 한 조각만 `clothes.gpt.candidate-dir`(기본값 `data/train-candidates/날짜/`)에 저장합니다.
  - 파일은 `아이디.jpg`와 `아이디.json`입니다.
  - json에는 GPT가 본 종류, 우리 모델 확신도, GPT 확신도, 모델 이름, `reviewed:false`를 적습니다.
  - 사용자 정보는 넣지 않습니다.
- 바로 학습하지 않습니다.
  1. 사람이 확인해서 `reviewed`를 true로 바꾼 것만 다음 학습에 넣습니다.
  2. 다시 학습한 모델은 시험 점수가 오를 때만 바꿉니다.
- `data/`는 .gitignore에 들어 있어 레포에 올라가지 않습니다.
- 보관 기간은 30일(`clothes.gpt.retention-days`)입니다. 새 날짜 폴더를 만들 때 30일이 지난 날짜 폴더를 지웁니다.

## 사용자 동의 (앱 처음 쓸 때 한 번, 정지원 11-09)

동의 문구에는 아래 세 가지가 꼭 들어가야 합니다(무늬는 정지원 11-11 추가).
- 얼룩인지 확실하지 않은 부분은 그 부분 사진 조각만 GPT(OpenAI)로 보내 확인합니다. 얼굴은 보내지 않습니다.
- 무늬를 모르는 옷은 **내려놓은 옷 사진일 때만** 그 옷 한 벌 부분을 GPT로 보내 확인합니다. 입은 사진은 보내지 않습니다.
- GPT가 얼룩이라고 한 사진 조각과, GPT에게 무늬를 물어본 옷 사진은 서버에 저장해 우리 모델 학습에 씁니다. 30일이 지나면 지웁니다.

문구 예: "얼룩인지 애매한 부분과 무늬를 모르는 옷은 그 부분만 잘라서 GPT로 확인해요. 얼굴이나 입고 찍은 사진은 보내지 않아요. 확인한 사진은 모델을 더 좋게 만드는 데 쓰려고 30일 동안 보관해요. 동의하시겠어요?"

동의하지 않으면 agent는 `allowGpt`를 보내지 않습니다. 그러면 GPT로 아무것도 보내지 않고 저장하지도 않습니다.

## 아직 남은 일 (다른 레포)

- agent: 동의한 사용자에게만 `allowGpt=true`를 보내기. `checkedBy=gpt`인 결함은 "~인 것 같아요"처럼 조금 약하게 말하기.
- 앱: 처음 쓸 때 동의 화면, 동의 여부 저장.

이 PR만 머지하면 GPT 확인은 켜지지 않습니다(`allowGpt` 기본값 false).

## 설정

| 환경 변수 | 뜻 | 기본값 |
| --- | --- | --- |
| `OPENAI_API_KEY` | OpenAI 키. 비면 GPT를 쓰지 않음 | (없음) |
| `CLOTHES_GPT_MODEL` | 모델 | `gpt-4.1-mini` |
| `CLOTHES_CANDIDATE_DIR` | 학습 후보 저장 폴더. 비우면 저장 안 함 | `data/train-candidates` |
| (yml) `clothes.gpt.timeout` | GPT 한 번 기다리는 시간 | `3s` |
| (yml) `clothes.gpt.fallback-ask-threshold` | GPT를 못 쓸 때 후보로 돌려줄 최소 확신도 | `0.3` |
| (yml) `clothes.gpt.retention-days` | 학습 후보 보관 날수 | `30` |

## 시험 결과 (11-09, 공개 데이터 시험 사진 314장)

얼룩·찢어짐이 있다/없다를 사진 단위로 맞혔는지 봤습니다. 보낸 조각은 v6가 0.2~0.5로 본 부분 149개뿐이고, 우리가 찍은 사진이나 얼굴 사진은 보내지 않았습니다.

| 방식 | 정답률 | 결함 찾음 | 깨끗한 옷 맞힘 |
| --- | --- | --- | --- |
| v6만 (0.5 / 0.2) | 93.0% | 79.8% | 99.5% |
| v6 + gpt-4.1-mini | **98.1%** | **95.2%** | 99.5% |
| v6 + gpt-5.4-mini | 96.8% | 92.3% | 99.0% |
| v6 + gpt-5.4 | 96.5% | 90.4% | 99.5% |

- GPT에게 묻는 사진은 전체의 8.3%입니다.
- 한 번에 약 0.9초가 걸립니다. 토큰은 입력 약 147개, 출력 약 14개로, 1원도 안 듭니다.
- 조각 하나씩 보면 진짜 결함 68개 중 56개를 맞혔고, 가짜 81개 중 52개를 "없음"으로 맞혔습니다.
- 시험 사진이 대부분 가까이 찍은 사진이라, 옷 전체 사진이나 입은 사진에서는 조금 낮을 수 있습니다.
