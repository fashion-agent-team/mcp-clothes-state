# 옷 색 인식 모델 (`color20_cnn.onnx`)

옷 박스 조각을 보고 색 20가지 중 하나를 고르는 작은 CNN입니다. 서버는 [`ColorModel`](../../src/main/java/com/fashionagent/clothesstate/color/ColorModel.java)로
이 모델을 돌리고, [`GarmentColor.fromModel`](../../src/main/java/com/fashionagent/clothesstate/color/GarmentColor.java)이 답을
`colorFamily`·`colorName`·`tone`으로 바꿉니다. 모델 파일이 없으면 예전 픽셀 규칙으로 돌아갑니다.

## 왜 만들었나

2026-11-11 [색 조합 규칙](../../docs/color-rules.md)을 AI Hub 코디 사진으로 검증해 보니 규칙은 거의 틀리지 않았는데(실제 코디에 "바꾸자" 0.1%),
**색 이름을 맞힌 옷이 67%뿐**이었습니다. 그늘진 흰 옷을 회색으로, 연청바지를 네이비로, 체크 옷을 엉뚱한 강한 색으로 봤습니다.
색 이름이 틀리면 사용자에게 틀린 색을 말하고 색 조합 판단도 틀어지므로, 사람이 색을 붙인 옷 사진으로 색 인식을 학습했습니다.

## 데이터

AI Hub [K-Fashion 이미지](https://aihub.or.kr) **Validation** (사진 120,975장, 받은 원천데이터 7GB + 라벨 131MB).
옷마다 사람이 붙인 `색상`(21가지), `서브색상`, `프린트`, `카테고리`와 정답 상자가 있습니다. Training(약 56GB)은 받지 않았습니다.

- 정답 상자로 옷을 잘라 긴 변 96px로 줄인 조각 **171,538벌**(사진 119,023장)을 썼습니다. 네온(890벌)은 너무 적어 뺐습니다.
- 사진 이름의 MD5로 나눠 한 사진의 옷이 한쪽에만 들어가게 했습니다: 학습 128,142 · 검증 16,880 · **시험 25,626벌**.
- 사진과 조각은 AI Hub 약관(재배포 금지)에 따라 레포·공유 폴더에 올리지 않습니다. 학습은 사용자 맥북에서 조각을 만든 뒤 클라우드 작업 공간에서 했고, 조각은 작업 뒤 지웁니다.

20가지 → 서버 `colorFamily`

| K-Fashion 색 | colorFamily | colorName |
| --- | --- | --- |
| 화이트 / 블랙 / 베이지 / 그레이 / 네이비 / 브라운 / 카키 | white / black / beige / gray / navy / brown / khaki | 흰색, 검정, 베이지, 회색(밝기에 따라 밝은 회색·차콜 그레이), 네이비, 갈색, 카키 |
| 실버 | gray | 은색 |
| 스카이블루 / 블루 | blue | 하늘색 / 파랑 |
| 레드 / 와인 | red | 빨강 / 와인색(어두움) |
| 핑크 | pink | 분홍(연하면 연분홍) |
| 그린 / 민트 | green | 초록 / 민트 |
| 퍼플 / 라벤더 | purple | 보라 / 연보라 |
| 옐로우 / 골드 | yellow | 노랑 / 겨자색 (K-Fashion 골드는 대부분 겨자색 옷) |
| 오렌지 | orange | 주황 |

`tone`은 하늘색·연보라·민트(light), 와인·네이비·검정(dark)처럼 색이 정해 주는 것 말고는 옷 픽셀 중간값의 밝기로 정합니다.
강한 색(빨강·파랑 등)은 채도가 낮고 밝을 때만 연한 색(`연한 ~`·하늘색·연분홍, light)으로 보고, 쨍한 빨강은 "밝은 빨강"이 아니라 "빨강"(mid)이라고 합니다.

## 비교한 방식 (시험 25,626벌, 2026-11-11)

| 방식 | 판단 | 색 계열(14가지) 정답률 | 흰 옷 | 강한 색이 아닌데 강한 색으로 | 강한 색을 놓침 | 크기 | 학습 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 픽셀 규칙 (옷 박스 가운데 중간값) | 이전 채택 | 45.3% | 15% | 6.6% | 60.1% | – | – |
| 색 히스토그램 314개 + 작은 신경망(MLP 256·128) | 비교 | 71.2% | 79% | – | – | – | CPU 23초 |
| **작은 CNN (64×64, 4단, 19만 개 가중치)** | **채택** | **76.8%** | **87%** | **5.8%** | **24.2%** | 0.8MB | CPU 18에폭 약 40분 |

- 강한 색 = 색 조합 규칙에서 눈에 띄는 색으로 보는 빨강·분홍·주황·노랑·겨자·초록·파랑·보라(연한 색·와인은 뺌).
  CNN은 두 실수를 **모두** 줄였습니다(헛 경고 6.6 → 5.8%, 놓침 60 → 24%).
- 20가지 그대로 맞힌 비율: MLP 66.9%, CNN 72.4%.
- 색별 정답률(CNN): 흰색 0.87, 검정 0.89, 파랑 0.87, 노랑 0.76, 분홍 0.74, 초록 0.73, 베이지 0.71, 갈색 0.71, 빨강 0.69, 회색 0.61, 보라 0.56, 주황 0.56, 네이비 0.52(검정·파랑과 헷갈림), 카키 0.46(베이지·갈색과 헷갈림).
- 무늬별: 무지 0.80, 레터링 0.85, 그래픽 0.75, 스트라이프 0.67, 플로럴 0.59, 체크 0.56. 무늬 옷이 여전히 약합니다.
- **틀린 것 40벌을 눈으로 봤더니** 모델이 분명히 틀린 건 4벌(하늘색 체크 → 흰색, 하운즈투스 → 검정 등)이고, 8벌은 라벨이 틀리고 모델이 맞았으며(검정 청바지를 네이비라고 한 라벨 등),
  나머지 28벌은 크림·아이보리를 흰색/베이지 중 무엇으로 부르느냐처럼 사람마다 다르게 부를 색이었습니다. 실제로 쓸 때의 정답률은 77%보다 높습니다.

학습 데이터에 없는 사진으로 확인:

| 시험 | 픽셀 규칙 | CNN |
| --- | --- | --- |
| AI Hub 2019 코디 사진 36장, 옷 77벌 눈 확인(서버 전체 순서: 옷 찾기 → 색) | 52벌 (67.5%) | **72벌 (93.5%)** |
| 그중 무작위 24장, 52벌 | 38벌 (73%) | **48벌 (92%)** |
| 검정·네이비 섞임(`dark_mix`)이 나온 사진 눈 확인 | 12장 중 1~3장 맞음 | **18장 중 13장 맞음** |
| 내려놓은 옷 45벌(Second-Hand Fashion 시험 사진, 흰 바닥) 눈 확인 | 34벌 (76%) | **37벌 (82%)** |

내려놓은 옷은 학습에 없어서 차이가 작습니다. 흰 바닥 위 흰·크림 옷을 밝은 회색으로 보는 실수가 남았습니다.

## 서버와 같은 값인지

- 서버(Java)는 조각을 `getScaledInstance(64, 64, SCALE_AREA_AVERAGING)`으로 줄이고, 학습(파이썬)은 96px 조각을 PIL `BOX`로 64px로 줄입니다.
- K-Fashion 원본 해상도 조각 60벌을 서버 경로(원본 → 64)와 학습 경로(원본 → 96 → 64)로 돌려 **60벌 모두 같은 답**(확률 차이 평균 0.002)이었습니다([`Parity.java`](Parity.java)).
- ONNX 출력은 PyTorch 평가와 500벌 모두 같았습니다.

## 다시 만드는 순서

```bash
# 맥북(라벨·사진 zip이 있는 곳)
python lab.py 0 200000 "K-Fashion 이미지/Validation/라벨링데이터.zip"     # → labels_0.csv (헤더 붙여 ~/kf/labels.csv)
python crop.py "K-Fashion 이미지/Validation/원천데이터.zip" 0 200000 crops   # 정답 상자 조각 96px + meta.csv
# 학습(torch 2.15, CPU 4코어)
python pack.py                        # 조각 → img64.npy (64×64)
python cnn.py 18 1                    # 18에폭, 폭 1 → cnn_w1.pt, pred_cnn_w1.npy, prob_cnn_w1.npy (중간에 끊겨도 이어서)
python export.py cnn_w1.pt color20_cnn.onnx
python score2.py pred_cnn_w1.npy      # 색 계열 정답률·헷갈린 색
python tradeoff.py prob_cnn_w1.npy pred_cnn_w1.npy   # 강한 색 헛 경고·놓침
# 비교용
java BaseEval crops test_meta.csv base_test.csv && python score.py test_meta.csv base_test.csv   # 픽셀 규칙
java FeatDump crops crops/meta.csv feats.f32 && python mlp.py                                    # 히스토그램 + MLP
```

`mlp.py`가 쓰는 히스토그램 특징값은 자바 [`ColorFeatures.java`](ColorFeatures.java)(서버 `GarmentColor`와 같은 패키지)로 뽑았습니다.
서버는 CNN만 쓰므로 이 파일은 서버 코드에 넣지 않고 비교 실험을 다시 돌릴 때만 씁니다.
